# Dixon-Coles 进球数预测模型 — 设计文档

> 用足球数学（football-mathematics-framework）从零重建进球数预测模型，与系统现有进球模型（Model B/C/D）彻底切割，仅复用现有系统的历史比分与市场赔率数据。

---

## 1. 背景与目标

系统现有进球预测是三层混合（Poisson 回归 + 市场融合 + 联赛经验校准），存在两个结构性缺陷：

| 现有模型 | 本质 | 缺陷 |
|---|---|---|
| Model B | Zero-Inflated Poisson 特征回归 | 黑箱特征工程，无攻防强度分解，xG 特征基本为空（xG 489/2072、xGA 0）导致退化 |
| Model C | 市场+基本面启发式融合 | 手写权重、联赛参数包、诱导评分，逻辑堆叠但非统计最优 |
| Model D | 「手写攻防比率法」 | 硬编码联赛基线、RHO=0.10 常量、无 MLE、无时间衰减——只是 Dixon-Coles 的粗糙近似 |

目标：落地足球数学领域的**标准范式**——Dixon-Coles 双变量泊松模型（Dixon & Coles 1997），从实际比分数据做 MLE，估计每队攻防强度，输出全场比分矩阵与总进球分布。

---

## 2. 核心模型

### 2.1 攻防强度分解（Maher 独立泊松 + Dixon-Coles 参数化）

对主队 h vs 客队 a：

```
λ_home = exp(mu + attack[h] + defense[a] + home_adv)
λ_away = exp(mu + attack[a] + defense[h])
```

- `attack[t]`：球队 t 的进攻强度（越高越能进球）
- `defense[t]`：球队 t 的防守弱点（越高越易失球）
- `home_adv`：主场优势（常数）
- `mu`：整体进球水平基线

这是对数线性（log-linear）参数化，是 Dixon-Coles 与 Maher 的共同内核。相比现有 ModelD 的「比率法」（`联赛基线 × 攻比率 × 防比率`），它由 MLE 直接从数据估计，不依赖硬编码联赛基线。

### 2.2 低分相关性修正 ρ（Dixon-Coles τ 函数）

独立泊松假设主客进球独立，但真实比赛中 0-0 / 1-1 的比分与独立性预测存在系统性偏差（球队领先/落后会改变战术节奏）。Dixon-Coles 引入 τ 修正：

```
τ(0,0) = 1 − λh·λa·ρ
τ(0,1) = 1 + λh·ρ
τ(1,0) = 1 + λa·ρ
τ(1,1) = 1 − ρ
其余 τ(x,y) = 1
```

联合概率 `P(x,y) = τ(x,y) · Pois(x|λh) · Pois(y|λa)`。ρ 由 MLE 估计（约束在 ±0.15 内，Dixon-Coles 原文 ρ 量级 ~0.1）。

### 2.3 时间衰减 ξ

球队状态随时间漂移，赛季初样本又少。用指数衰减给近期比赛更高权重：

```
weight_t = exp(−ξ · (T_ref − t))
```

ξ 默认 0.003（半衰期 ~231 天 ≈ 半赛季）。这是「样本量 < 6 场不可靠」这条启发式的平滑替代——不是截断，而是连续降权。

### 2.4 L2 收缩（关键，对应真实数据特征）

实测唯一球队 1,238 支，**每队场次中位数仅 4 场**（重尾分布：P90 才 59 场）。低样本球队的攻防强度极易过拟合（把噪声当信号，框架反模式 2）。用 L2 正则把低样本球队收缩到联赛均值：

```
penalty = l2_reg · (Σ attack² + Σ defense²)
```

`l2_reg` 默认 0.5。这同时解决了 attack/defense 的可识别性（shift 不变性由最小范数解唯一化）。

---

## 3. 参数估计（MLE）

目标函数 = 加权负对数似然 + L2 正则：

```
−Σ_t w_t·[ log τ_t + x_t·log λh − λh − log x_t! + y_t·log λa − λa − log y_t! ]
  + l2_reg·(Σ attack² + Σ defense²)
```

用 `scipy.optimize.minimize`（L-BFGS-B + **解析梯度**，含 τ 修正项的链式求导）求解。参数向量 ~2×球队数+3（当前最多 ~2,500 维）。

**可识别性**：`attack` 整体 +c、`defense` 整体 −c 不改变 λ，L2 正则把解收敛到最小范数（即自动中心化），无需显式约束。

## 4. 数据依赖（复用现有系统数据）

| 数据 | 表 | 用途 |
|---|---|---|
| 历史比分 | `matches` (home/away_score, home/away_team_id, kickoff_time) | MLE 训练攻防强度 + 时间衰减 + 主客口径 |
| 联赛 | `leagues` | 分联赛统计 / 诊断 |
| 竞彩 TTG 赔率 | `jczq_play_odds_snapshots.ttg_odds_json` | 市场隐含分布（后融合 + ROI 计价） |

**未用**：xG/xGA（库中基本为空）、H2H（已被市场定价，见项目记忆 2026-10-11 结论）、伤病、传球网络。

---

## 5. 市场后融合（基本面为主 + 市场做后融合）

纯基本面 Dixon-Coles 输出总进球分布 `p_fund(k)`，与 TTG 市场隐含分布 `p_mkt(k)`（1/赔率归一化）做**几何均值融合（log-linear pooling）**：

```
p_fused(k) ∝ p_fund(k)^w · p_mkt(k)^(1−w)
```

w = 基本面权重。w=0 纯市场（≈现状信号）、w=1 纯基本面。回测扫 w ∈ {0, 0.25, 0.5, 0.75, 1} 找到最优口径。

---

## 6. 回测验证（防泄露）

- **Walk-forward 逐周重训**：每 7 天重训一次，训练集 = `kickoff < 重训日` 的全部历史（含时间衰减），预测 `[重训日, 重训日+7)` 的场次。
- 预热 180 天 / 3000 场后才开始预测。
- 市场赔率取开赛前最新快照，无未来信息。

**评估口径**（对齐竞彩「进球数」0/1/2/3/4/5/6/7+ 八档）：

1. 大小球方向命中率（O/U 2.5，全量 + |P−0.5| 门控）
2. 进球数 Top-3 选覆盖（p_hit = 实际进球 ∈ 选中 3 档）
3. Top-3 复式 ROI（竞彩实际赔率计价，stake=3/场）
4. log-loss（严格评分规则，判断谁预测更准）

三路对比：market（TTG 隐含=现状）/ dc（纯 Dixon-Coles）/ fused（融合）。

---

## 7. 诚实边界（框架第七部分）

1. 足球是低得分高随机运动，单场进球数分布方差极大，任何模型命中率有天花板（Top-2 盲猜上限 ~55%）。
2. 泊松假设忽略比赛内节奏联动（红牌、领先摆大巴），极端场次必偏。
3. 攻防强度是「赛季均值」概念，无法捕捉伤病/轮换/士气等突变。
4. 中位 4 场的球队即使 L2 收缩，估计仍不稳定——这是数据约束，不是模型能解决的问题。
5. 若市场已充分定价攻防强度，纯基本面模型的增量会被市场吸收（框架镜片 6：价值在于发现「市场/直觉低估」的信号）。
6. 本模型是决策辅助，不是「保证赢球」的方法。
