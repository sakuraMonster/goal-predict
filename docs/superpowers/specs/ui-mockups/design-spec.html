进球数预测展示页面 — 设计规范说明书

版本 v1.0 · 2026-08-05 · 竞彩足球预测系统 · UX 设计智能体输出

1. 概述与设计目标

本规范定义两个全新产品页面的设计：「当前比赛预测查看」（路由 /live）和 「历史报告」（路由 /report/history），围绕足球进球数预测（SNAP Top2）这一核心数据，构建从实时监控到历史复盘的全链路查看体验。

1.1 设计原则

  1. 渐进式加载：无论后端数据是否就绪，优先展示完整 UI 骨架，绝不出现空白页面
  2. 信息层级分明：核心预测数据（SNAP Top2、置信度）视觉优先级最高，支撑数据按需展开
  3. 编辑感排版：延续项目"Editorial Product Hybrid"风格，羊皮纸底色 + 白色内容卡片 + 衬线标题
  4. 多端一致：所有触控交互区域 ≥ 48x48px，移动端单列布局无缝降级

1.2 页面路由与导航关系

路由页面名称导航入口关联页面
/live当前比赛预测查看主导航"赛事预测"替换为"实时预测"tab点击卡片 → 详情面板（侧滑）；无跳转
/report/history历史报告主导航"预测报告"下拉菜单新增"历史报告"点击"重新预测" → 弹窗确认；可跳转到 /match/:id
注意：两个页面不与现有 Dashboard、Report 页面冲突。/live 侧重于"正在进行中比赛的实时监控"；/report/history 侧重于"已结束比赛的历史数据统计与复盘"。现有 / Dashboard 仍保留按日期查看所有赛事的功能。

4.2 Skeleton 复用原则

复用现有组件：SkeletonCard 已实现 animate-pulse opacity-50 的卡片骨架。页面一直接复用 6 个 SkeletonCard。
新增骨架：环形图骨架（160px 圆 + 文字条）、图表区骨架（矩形占位）、表格骨架（行级 pulse），参考现有 SkeletonCard 的 animate-pulse + opacity-50 模式。
